## 2. STRIDE-разбор

Для каждого элемента потока данных (процесс/хранилище/стрелка) пройтись по STRIDE:

| ID | Элемент | S: Подмена | T: Изменение данных | R: Отрицание совершённого действия | I: Утечка инфо | D: Отказ в обслуживании | E: Эскалация привилегий |
|---|---|---|---|---|---|---|---|
| TM-01 | API gateway | session hijacking | | | | flood | token scope |

Формулировка угрозы: «Злоумышленник <кто> может <действие>, чтобы <цель>».
