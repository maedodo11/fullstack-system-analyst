# Практикум «Запись на приём»

**Результат:** согласованный пакет аналитики, который можно объяснить разработчику, тестировщику и заказчику. Учебная клиника и все её данные вымышлены. Проект не содержит медицинских рекомендаций.

Это разобранный пример с заданиями, а не готовая промышленная система. Базовая версия: взрослый пациент записывает себя на бесплатный приём. Платежи, медицинская карта, несовершеннолетние и страхование исключены из объёма.

| Шаг | Работа | Артефакт | Время на первую попытку |
|---|---|---|---|
| 1 | Уточнить проблему | [Интервью и границы](01_discovery.md) | 45–60 мин |
| 2 | Сделать поведение проверяемым | [Требования и Use Case](02_requirements.md) | 60–90 мин |
| 3 | Согласовать данные и состояния | [Модель данных](03_data.md) | 60–90 мин |
| 4 | Договориться об интеграции | [Контракт API](04_api.md) | 60–90 мин |
| 5 | Распределить ответственность | [BPMN-процессы](05_processes.md) | 45–60 мин |
| 6 | Доказать выполнение требований | [Проверки и трассировка](06_acceptance.md) | 60–90 мин |
| 7 | Отработать новое пожелание | [Изменение: перенос записи](07_change.md) | 60–90 мин |
| 8 | Защитить результат | [Критерии сдачи](08_delivery.md) | 30–45 мин |

Время — ориентир для самостоятельной работы, без гарантии темпа. На каждом шаге сначала выполните задание, затем откройте разбор. Записывайте допущения отдельно от фактов.

**Правило согласованности:** одинаковый `slot_id` означает один и тот же слот в требованиях, БД, API и тестах; статус `CONFIRMED` везде означает успешно созданную запись. Изменение одного правила проверяется по [матрице трассировки](06_acceptance.md).
