# 8. Сдача и защита проекта

[Назад](07_change.md) · [Проект](README.md) · [Курс](../README.md)

## Пакет сдачи

1. Краткое описание проблемы, границ и метрики.
2. Требования с ID, Use Case и альтернативами.
3. ER, словарь, состояния и инварианты.
4. OpenAPI с примерами успеха, ошибок и повторов.
5. Две BPMN-модели с исходниками и объяснением ответственности.
6. Матрица трассировки и план испытаний.
7. Impact analysis CR-01 и ADR о выбранном варианте.

## Рубрика: 20 баллов

По каждому критерию: 0 — отсутствует/противоречит другим документам; 1 — частично раскрыт; 2 — проверяемо и согласованно.

| Критерий | Признак двух баллов |
|---|---|
| Проблема | Факты отделены от гипотез, есть владелец |
| Границы | In/out scope и допущения явны |
| Метрика | Числитель, знаменатель, период и источник |
| Требования | ID, наблюдаемое поведение, альтернативы |
| Данные | Кардинальности и конкурентные инварианты |
| API | Авторизация, ошибки, повтор, контракт |
| BPMN | Корректные потоки, роли, исходы и таймер |
| Проверки | Позитивные, негативные и конкурентные сценарии |
| Изменение | Влияние на все связанные артефакты |
| Защита | Обоснованы альтернативы и ограничения |

Учебный порог — 16/20, без нуля в данных, API и проверках. Это критерий данного практикума, не отраслевой сертификат. [Образцы качества ответов](../practice/assessment.md).

## Защита за 10 минут

2 минуты — проблема и границы; 3 — один сценарий через требования/API/данные; 3 — отказ или гонка; 2 — CR-01 и последствия. Затем ответить: «Как доказать, что пациент не потеряет запись при сбое?»

## Редакторская проверка перед публикацией

- У всех схем есть заголовок, исходник и текстовое объяснение.
- В примерах нет реальных пациентов, секретов и выдуманных результатов исследований.
- Каждое число либо измерено с указанием условий, либо помечено как допущение.
- Ссылки открываются; исполняемые примеры запускаются по инструкции.
- План испытаний отделён от фактически выполненных проверок.
- Второй читатель проходит сценарий без устного объяснения автора; замечания фиксируются и устраняются.
