# Как улучшать курс

1. Меняйте текст и PlantUML вместе: имена участников, статусы, суммы и ветки должны совпадать.
2. У каждого примера указывайте допущения, вход, результат и отказ. Сначала дайте задание, решение скройте в details.
3. Метрики проверяемы: окно, нагрузка, точка измерения, порог и способ проверки. Не выдавайте учебные числа за измерения.
4. Проверяйте спорные утверждения по первоисточникам; фиксируйте версию стандарта/продукта. Правовые требования не выводите из одного названия закона.
5. Для рендера нужны Java 17+ и Graphviz (dot). SVG и PNG пересобирайте из исходников командой `bash render_all.sh`; рассматривайте изображения после рендера. Ошибка PlantUML должна останавливать сборку.
6. Выполните `python3 tools/check_course.py` и `python3 tools/check_examples.py`. Полную OpenAPI-валидацию выполняет CI отдельным валидатором.

Симулятор демонстрирует последовательные инварианты, а не производственный платёжный сервис. PostgreSQL DDL проверяется на настоящем PostgreSQL в CI; SQL HAVING также запускается в SQLite. Сетевые операции, подписи и гонки между инстансами требуют отдельной реализации и интеграционных тестов.

При изменении image-стиля просмотрите широкую ER/карту и длинную sequence-схему: успешный рендер ещё не доказывает читаемость.

## Сквозной проект и BPMN

```bash
python tools/check_project.py
npm ci --prefix tools/bpmn
npx --prefix tools/bpmn playwright install chromium
node tools/bpmn/render.cjs
```

BPMN редактируется в project/bpmn/*.bpmn, SVG экспортируется из той же модели через bpmn-js. Сначала проверяется успешный импорт обеих моделей, затем заменяются SVG. Не редактируйте экспорт вручную. npm ci использует lockfile; CI проверяет импорт и пересборку. При изменении проекта сверяйте FR, API, словарь, процессы и матрицу приёмки.

Редакционный минимум: обозначить аудиторию и результат урока, отделить факты от учебных допущений, дать задание и критерии, объяснить каждую схему, раскрыть отказ и границу применимости. Внешнее педагогическое ревью и пилот с читателями фиксируются отдельно от автоматических проверок.
