# SQL: WHERE → GROUP BY → HAVING

[Продолжение: 10 проверяемых SQL-заданий](lab/README.md)

Исполняемый пример [having.sql](having.sql) совместим с MySQL 8+ и SQLite 3. Таблица учебная, суммы в целых рублях. Скрипт удаляет и пересоздаёт **только учебную таблицу training_store_sales**; запускайте в отдельной учебной БД.

В MySQL Workbench: откройте файл, выберите учебную схему, выделите весь скрипт и выполните. Перед запуском предскажите ответ.

Задание: посчитать сумму оплаченных продаж по городам, оставить только сумму >10000, отсортировать по убыванию. Неоплаченные строки не должны влиять на результат.

<details>
<summary>Ожидаемый результат и разбор</summary>

| city | total_amount |
|---|---:|
| Иркутск | 15000 |
| Казань | 12000 |

Москва даёт ровно 10000, поэтому не проходит строгий порог >10000. Новосибирск даёт 0 оплаченных продаж. У Иркутска отменённая продажа 50000 исключается WHERE. При пороге >15000 строк нет.

</details>

Дополнительно: замените SUM на AVG и опишите смысл результата. COUNT(*) считает строки, COUNT(column) исключает NULL. Не меняйте WHERE на HAVING для фильтра статуса.
